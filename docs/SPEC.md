# CreatLifePlan 仕様書（v0.2）

> ライフプランをシミュレーションし、「将来お金が足りるか」を確認して安心するための Web アプリ。
> 本書は叩き台です。【要望】= いただいた要望、【提案】= こちらからの追加提案。採否を決めながら更新していきます。

---

## 1. 目的・ゴール

| # | ゴール | 区分 |
|---|--------|------|
| G1 | 生涯（例：100歳まで）の資産推移を見て「お金が足りる／足りない」を一目で判断できる | 要望 |
| G2 | 現在の収入・固定費・変動費から「毎月あといくら使えるか」が分かる | 要望 |
| G3 | 積立投資額と利回りから将来の資産額が分かる | 要望 |
| G4 | 子供の養育費・教育費を含めて計算できる | 要望 |
| G5 | 結婚・住宅・車などの大きなライフイベント費用を含めて計算できる | 要望 |
| G6 | グラフで年ごと・項目ごとに細かく確認できる | 要望 |
| G7 | 結果を Excel（スプレッドシート）に出力できる | 要望 |
| G8 | 足りない場合に「何をどれだけ変えれば足りるか」が分かる | 提案 |

## 2. 基本方針

### 2.1 費用のバッファ（1.1倍ルール）【要望】
- アプリが持つ「世間一般の費用（標準値）」を使う項目は **標準値 × 1.1** で計算する。
- 【提案】バッファ率は設定画面で変更可能（初期値 1.1）。
- 【提案】ユーザーが実額を手入力した項目にバッファを掛けるかは項目ごとに ON/OFF 可能にする。
  - 初期値：標準値を使った項目 = ON、実額入力した項目（家賃・ローン返済など確定額）= OFF
- 【提案】グラフ・表では「うちバッファ分」を別色/別列で表示し、どれだけ余裕を見ているか分かるようにする。

### 2.2 インフレ・物価上昇【提案】
- 将来の費用は物価上昇率（初期値 年1.0%〜2.0%、設定可）で増加させる。
- 表示は「名目額」と「現在価値（今のお金に換算）」を切替可能にする。
  - 何十年も先の金額は名目だと実感しづらいため、現在価値表示を推奨。

### 2.3 データ保存・プライバシー【提案】
- 家計情報はセンシティブなため、**初期版はサーバーに送らずブラウザ内（localStorage / IndexedDB）に保存**。
- JSON ファイルでのエクスポート／インポート（バックアップ・別端末への移行用）。
- 【要望・実装済】外部に漏らさずプランを保存する：
  - 複数プランをブラウザ内に自動保存（保存・複製・名前変更・削除）
  - バックアップにパスワードを設定すると AES-256-GCM で暗号化（鍵は PBKDF2-SHA256 で導出）。ファイルが漏れても中身は読めない
  - 本番ビルドは CSP `connect-src 'none'` で外部通信を禁止し、データ送信が起きないことを保証
  - 「この端末のデータをすべて削除」ボタン
- 将来的にログイン・クラウド保存を追加する場合は別途検討。

### 2.4 計算単位
- シミュレーションは **年単位**（1年 = 1行）で計算。
- 家計（G2）は **月単位** で計算・表示。
- 期間：現在〜本人が100歳（終了年齢は設定可）。

## 3. 機能一覧

### F1. 家族・基本情報
| 項目 | 内容 |
|------|------|
| 本人 | 生年月日（年齢）、職業区分（会社員/公務員/自営業など） |
| 配偶者【提案】 | 有無、生年月日、職業区分、収入 |
| 子供 | 既にいる子＋**予定の子**（誕生予定年）を複数登録 |
| 設定 | シミュレーション終了年齢、物価上昇率、バッファ率 |

### F2. 収入【要望＋提案】
- 本人・配偶者それぞれの年収（額面）を入力。
- 【提案】**額面 → 手取り自動計算**（所得税・住民税・社会保険料の概算）。手取りを直接入力も可。
- 【提案】昇給率（年%）と昇給が止まる年齢（例：50歳で頭打ち）。
- 【提案】収入変化イベント：産休・育休（育児休業給付金）、時短勤務、転職、定年、再雇用（例：60〜65歳は年収7割）。
- 【提案】退職金（受取年齢・金額）。
- 【提案】**公的年金**：受給開始年齢（60〜75歳、繰上げ/繰下げ）と年額。ねんきん定期便の見込額入力 or 加入年数と年収からの概算。
- 【提案】児童手当（子供の年齢に応じ自動計算）。
- その他収入（副業、家賃収入など）。

### F3. 支出（家計簿）＝「月いくら使えるか」【要望】
- **固定費**：住居費（家賃/ローン）、水道光熱費、通信費、保険料、サブスク、車関連、教育費（習い事）など
- **変動費**：食費、日用品、交際費、趣味・娯楽、被服、医療費など
- 画面で以下を表示：
  ```
  月の手取り
  − 固定費
  − 先取り貯蓄・投資額
  ＝ 変動費に使える額（目標）
  − 変動費（現状）
  ＝ 自由に使える余裕額（月）
  ```
- 【提案】特別費（年払い：帰省、家電買替、車検、固定資産税など）を年額で入力し、月割り表示。
- 【提案】**総務省「家計調査」の世帯構成別平均との比較**表示（使いすぎ項目が分かる）。
- 【提案】老後の生活費は「現役時の◯%」または手入力で設定（初期値：現役生活費の70%）。

### F4. 貯蓄・投資【要望】
- 現在の資産：預貯金、投資（NISA、iDeCo、特定口座）、その他。
- 毎月の積立額と想定利回り（年%）を口座/商品ごとに設定。
- 【提案】**NISA・iDeCo の制度上限**を反映（NISA 年360万・生涯1,800万、iDeCo は職業区分ごとの上限）。iDeCo は60歳まで引出し不可として扱う。
- 【提案】積立期間（開始〜終了年齢）と、**取り崩し計画**（何歳から月いくら／定率で取り崩すか）。
- 【提案】**生活防衛資金**（生活費の◯か月分、初期値6か月）を下回る場合は投資資産から補填、またはアラート。
- 【提案】現金が不足した年は投資資産から自動取り崩しする設定。
- 【提案】利回りのシナリオ：楽観 / 標準 / 悲観 の3本を同時に表示。
- 【提案（Phase 3）】モンテカルロ・シミュレーション（リターンのブレを考慮し「資産が尽きない確率 ◯%」を表示）。

### F5. 子供の養育費・教育費【要望】
子供ごとに進路を選択 → 標準費用 × 1.1 × 物価上昇 を自動計上。

| 段階 | 選択肢 |
|------|--------|
| 出産 | 出産費用（出産育児一時金50万円を差し引き） |
| 未就学（0〜5歳） | 保育園 / 幼稚園（公立/私立）/ 家庭保育 |
| 小学校 | 公立 / 私立 |
| 中学校 | 公立 / 私立 |
| 高校 | 公立 / 私立 |
| 大学等 | 進学なし / 専門学校 / 国公立 / 私立文系 / 私立理系 / 私立医歯系 |
| 住まい | 自宅通学 / 下宿（仕送り） |

- 教育費とは別に **生活費としての養育費**（食費・衣類・お小遣い・医療など）を年齢別で計上。
- 塾・習い事の追加費用、留学などのオプション。
- 【提案】高校無償化・保育無償化など公的支援は「反映する/しない」を設定（制度変更リスクがあるため）。

### F6. ライフイベント【要望】
テンプレートから選んで年と金額を調整。標準費用 × 1.1 で自動入力。

| イベント | 内容・計算 |
|----------|-----------|
| 結婚 | 挙式・披露宴、新生活準備（ご祝儀収入も入力可） |
| 出産 | F5 と連動 |
| 住宅購入 | 物件価格、頭金、諸費用（物件価格の7〜10%）、**住宅ローン**（借入額・金利・期間・元利均等/元金均等）、固定資産税、修繕費、【提案】住宅ローン控除 |
| 賃貸更新・引越し | 更新料、引越し費用 |
| 車購入 | 購入価格、買替サイクル（例：10年ごと）、維持費 |
| リフォーム | 実施年・金額 |
| 旅行 | 毎年 or 特定年 |
| 子供の結婚援助 | 金額・年 |
| 介護（親・自分） | 一時費用＋月額×期間 |
| 葬儀・お墓 | 金額 |
| 自由入力 | 任意の名前・年・金額・繰り返し |

- 【提案】繰り返しイベント（「◯年ごと」）に対応。
- 【提案】一時的な収入イベント（相続、保険満期など）にも対応。

### F6b. いくらの家なら買えるか【要望・実装済】
- 今のライフプランに住宅購入（購入年・頭金・金利・期間は「住宅購入の予定」の値）を組み込み、価格を変えてシミュレーションして次の価格を求める。
  - **安心ライン**：悲観シナリオでも資金がショートせず、返済負担率（年間返済額 ÷ 購入年の世帯手取り）が 25% 以内
  - **上限**：標準シナリオで資金がショートしない最大価格（超えた場合に何年・何歳でショートするかも表示）
- 固定資産税は価格に比例させ、諸費用・修繕費はバッファ込み。
- 毎月の返済額・返済負担率・退職時の金融資産を比較表で表示し、「この価格で試算する」ボタンで予定に反映できる。
- アドバイス：安心ライン／上限、注意ゾーン、完済年齢が75歳超の場合の注意、購入時に必要な現金、金利上昇への備え。
- 住宅なしでもショートする場合は、家計の見直しを先に促す。
- ダッシュボードにも「買える家の目安」を表示。

### F7. シミュレーション計算【要望】
年ごとに以下を計算：

```
年間収入（手取り＋年金＋手当＋その他）
− 基本生活費（物価上昇考慮）
− 住居費
− 教育費・養育費（×1.1）
− ライフイベント費（×1.1）
− 積立投資額
＝ 年間収支（現金の増減）

現金残高   = 前年現金 + 年間収支 (+ 投資からの取り崩し)
投資残高   = 前年投資 × (1 + 利回り) + 積立額 − 取り崩し
総資産     = 現金残高 + 投資残高 − ローン残高
```

- **判定**【提案】
  - 現金がマイナスになる年 → 「赤字年」として警告
  - 総資産が0を下回る年 → 「資産枯渇年齢」を表示
  - 終了年齢時点の残資産を表示
  - 総合判定：🟢安心 / 🟡注意 / 🔴不足
- 【提案】**改善提案**（G8）：不足時に「毎月あと◯円積み立てれば足りる」「生活費を月◯円下げれば足りる」「定年を◯歳延ばせば足りる」を逆算して表示。

### F8. グラフ・表示【要望】
| グラフ | 内容 |
|--------|------|
| 資産推移（メイン） | 積み上げ面グラフ：現金／投資／（負債はマイナス側）。資産0ラインと枯渇年を強調 |
| 年間収支 | 棒グラフ：収入 vs 支出、差額を折れ線 |
| 支出内訳 | 積み上げ棒：生活費・住居・教育・イベント・バッファ分 |
| 月の家計 | 円グラフ or 横棒：固定費・変動費・貯蓄の内訳 |
| 投資の伸び | 元本 vs 運用益の積み上げ |
| シナリオ比較【提案】 | 複数プランの資産推移を重ねて表示 |

- 横軸は「西暦」「本人年齢」「子供の年齢」を切替/併記。
- グラフの年をクリック → その年の内訳詳細（表）を表示（"細かく見れる"）。
- ライフイベントをグラフ上にアイコン表示（🎓🏠🚗など）。
- 期間ズーム（例：今後10年だけ表示）。
- 年次キャッシュフロー表（一般的な「キャッシュフロー表」形式）も表示。

### F9. Excel（スプレッドシート）出力【要望】
- `.xlsx` ファイルをダウンロード。シート構成案：

| シート | 内容 |
|--------|------|
| サマリー | 判定結果、資産枯渇年齢、主要前提条件 |
| 前提条件 | 入力値一覧（収入、物価上昇率、利回り、バッファ率など） |
| 月次家計 | 固定費・変動費・使える額 |
| キャッシュフロー表 | 年×項目（収入・支出内訳・収支・資産残高） |
| 教育費 | 子供ごと・年ごとの内訳 |
| ライフイベント | イベント一覧 |
| 標準費用マスタ | 使用した標準値と出典、1.1倍後の値 |

- 【提案】数値だけでなく**Excel 上でも計算式を残す**（前提を Excel 上で変えても再計算される）かどうか → 要相談（下記 §7）。
- 【提案】グラフも Excel 内に埋め込む。
- 【提案】Google スプレッドシートで開けることを確認（xlsx をアップロードすれば開ける）。CSV 出力も併設。

### F10. シナリオ（プラン）管理【提案】
- 複数プランを保存・複製・比較（例：「子供2人」vs「子供3人」、「賃貸」vs「持ち家」、「私立」vs「公立」）。
- 比較画面で資産推移グラフを重ねて表示。

### F11. 入力支援【提案】
- 初回はウィザード形式（家族 → 収入 → 支出 → 資産 → 子供 → イベント → 結果）。
- 「分からなければ標準値で入力」ボタン。
- 各項目にヘルプ（何を入れればいいか、標準値の根拠）。

## 6. 技術構成（案）

| 項目 | 案 | 理由 |
|------|----|------|
| フロント | React + TypeScript + Vite | 型で計算ロジックの安全性を担保 |
| UI | Tailwind CSS + shadcn/ui 等 | 入力フォームが多いため |
| グラフ | Recharts（または ECharts） | 積み上げ・ズーム・クリック詳細に対応 |
| Excel 出力 | ExcelJS | 書式・数式・複数シートに対応 |
| 保存 | localStorage / IndexedDB（サーバーなし） | 個人情報を外部送信しない |
| テスト | Vitest | 計算ロジック（税・ローン・複利）の単体テスト |
| ホスティング | GitHub Pages / Vercel など静的ホスティング | バックエンド不要 |

- 計算ロジックは UI から分離した純粋関数（`src/engine/`）として実装し、テストで検証する。
